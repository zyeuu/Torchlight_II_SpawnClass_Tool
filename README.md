# Torchlight II SpawnClass Tool

《火炬之光 II》的离线掉落调用图、物品来源索引和修改草稿编辑器。

## 使用

用现代浏览器打开 `index.html`，即可进入共享掉落调用图。无需安装依赖或构建，也不需要游戏的完整 `MEDIA` 目录。复制或下载项目时，请保留全部网页及 `编辑器/` 文件夹。

在「🔧 修改草稿」中可导出 ZIP，或导入本工具此前导出的 ZIP。导入先检查内容并显示预览，确认后整体替换当前草稿，未包含在 ZIP 中的原有修改会被清除。旧版不带草稿记录的 ZIP 也可恢复；无法完整还原的修改会报错并保留当前草稿。

草稿保存于浏览器本地存储，不属于 Git 中的项目文件。更换浏览器、电脑或文件夹路径后，如草稿为空，请导入之前导出的 ZIP 恢复。升级工具后，请刷新所有已打开的索引页面。

导出的 `MEDIA/*.DAT` 是修改后的完整源文件，需要在 GUTS 项目中编译打包为 MOD。网页不直接读取或安装游戏目录里的 `.MOD`。

## 文件结构

| 文件 | 用途 |
| --- | --- |
| `index.html` | 默认入口，跳转到共享调用图 |
| `共享掉落调用图.html` | 共享节点调用图、上下游追踪、详情和修改入口 |
| `特殊掉落表.html` | 掉落表原值、条目、来源和修改入口 |
| `物品与任务来源.html` | 类型候选物品、Unique／Legendary／Quest 来源及稀有度修改 |
| `点名物品速查.html` | 直接引用具体物品的掉落表索引 |
| `按来源追踪掉落路径.html` | 从怪物、宝箱等入口展开掉落路径 |
| `共享掉落主线概览.svg` | 可跳转至详细调用图的主线概览 |
| `通用掉落抽取流程.svg` | 通用抽取过程说明 |
| `编辑器/草稿.js` | 编辑、标记同步、导入预览和 ZIP 导出 |
| `编辑器/导入.js` | 校验 ZIP、恢复修改、验证重新导出的 DAT |
| `编辑器/草稿存储.html` | 浏览器本地存储及跨页同步 |
| `编辑器/目录.js` | 物品、类型、掉落表的内嵌索引 |
| `编辑器/原始DAT.js` | 导入对照和导出所需的压缩源文件基线 |
| `编辑器/编辑.css` | 编辑器和修改状态样式 |
| `编辑器/jszip.min.js` | ZIP 读写依赖 |

## 数据与行为

- 数据是生成索引时的游戏资源快照，不会自动随游戏或 MOD 更新。
- 文件路径与行号仅作为参考文字，网页不读取外部 DAT 或场景文件。
- 图中红色问号标识含 NONE 的表，金色星标标识相关镶嵌物分支，扳手标识有草稿修改的节点。
- 修改与原始数据分开保存；移除条目以灰色划线显示，新增条目以黄色显示。
- 概率是指定表中的分支比例。物品生成还可能受等级、职业、物品稀有度和其他条件影响。

## 开发

这是无构建步骤的静态项目。三个交互页面共享 `编辑器/` 下的代码，调用图布局运行时已内嵌在 HTML 中。

修改共享编辑器后，应在独立目录检查调用图、物品列表、跨页同步，以及 ZIP 导入 → 再导出的内容一致性。导入必须在全部文件通过校验后才写入草稿，失败不能部分覆盖已有修改。

依赖包括 JSZip 3.10.1，以及调用图内嵌的 Viz.js／Graphviz 运行时。保留文件中的第三方声明。游戏数据及名称来自 Torchlight II。
